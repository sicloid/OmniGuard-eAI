# Tarihsel V2 kaynak paketi

Bu dizindeki yedi `*_V2.md` dosyası, ChatGPT Plus Tanıtımı sohbetindeki self-hosted
mimariye geçişin orijinal kaynaklarıdır. İçerikleri tarihsel iz için korunur;
başlarına güncel dokümanlara yönlendirme eklendi. Check-list'ler, rol seçimi,
başlangıç yönergeleri, örnek dosya yolları ve takvimler güncel uygulama durumu değildir.

Güncel giriş: [AI bağlamı](../../AI_SYSTEM_PROMPT.md), [repo kuralları](../../AGENTS.md),
[V3 mimari](../../ARCHITECTURE.md), [gerçek durum](../STATUS.md).
Onaylı runtime: [SCHEMA](../../SCHEMA.md), [ADR-0001](../adr/0001-foundation.md).
Yeni öneriler: [ADR-0002](../adr/0002-bounded-containment.md).

Son sohbet 00_PROJECT_CONTEXT ve 08_MIGRATION_CHANGELOG dahil dokuz dosyadan söz
ediyor; repo başlangıcında yedi V2 dosyası var. Eksik iki orijinal dosyanın aynısını
okuduğumuzu veya yeniden ürettiğimizi iddia etmiyoruz. Güncel mimari bağlamı ve
evrim kaydı [2026 değerlendirmesinde](../architecture/REVIEW_2026.md) yer alır.
