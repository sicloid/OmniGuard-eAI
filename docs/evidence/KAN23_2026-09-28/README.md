# CICIoT2023 local raw-data inventory

`inventory.json` is generated by `python -m data.ciciot2023.inventory` over the
downloaded `PCAP/` tree. It pins every local PCAP by path, role/folder, size and
SHA-256 so the downloaded data is part of the project evidence rather than an
untracked directory.

Inventory does not make every attack capture suitable for the current EGRESS
detector. Each admitted experiment still needs a declared role and topology
audit. The four `Benign_Final` files are processed through the same raw-PCAP
extractor with observed MAC-derived device groups for the new-device benign
evaluation. LOCAL attack folders remain available for a separately declared
lateral-traffic detector and are not relabelled as EGRESS.
